## 🤔 What is this?

**Troll Calculator** is a fully functional-looking calculator that trolls you every single time you press `=`. Instead of giving you the actual result, it fires back with sarcastic, chaotic, and completely useless responses — because why do math when you can do *vibes*?

Type in `2 + 2`, hit `=`, and get hit with:
> *"ran the numbers. the numbers ran away."*

Try `999 × 7`, and receive:
> *"i'm legally not allowed to answer."*

It looks like a calculator. It acts like a calculator. It is not a calculator.

---

## ✨ Features

- 🔢 Full calculator UI — number pad, operators, clear, sign toggle, percentage
- 🎲 **25 unique troll responses** — randomly served every time you hit `=`
- 💬 **Sarcastic subtitles** — a little "// trust me bro" under every fake answer
- 🏷️ **Banner quips** — a second wave of sass that fades in 400ms after the answer
- 💻 **Blinking terminal cursor** — because aesthetics
- 📺 **CRT scanline overlay** — retro screen effect on the display
- 🌙 **Dark neon theme** — cyan `#0ff` + hot pink `#ff2d95` + blood red `#ff4444`
- ⚡ **Zero dependencies** — pure HTML, CSS, and vanilla JavaScript
- 📦 **Single file** — open in any browser, no build step, no npm, no drama

## 🚀 Usage

Just open the file. That's it.

````bash
git clone https://github.com/your-username/troll-calculator.git
cd troll-calculator
open troll_calculator_neon.html   # or double-click it
````

No install. No framework. No math.
